# 공문 일정 비서

공문·메일·한글·PDF·엑셀에서 일정을 뽑아 담고, 취합 건은 회신기한까지 계산해 주는 도구입니다.
봉화군 도시계획과 서무 업무용으로 만들었습니다.

## 쓰는 법

주소를 열면 바로 씁니다. 설치도 가입도 필요 없습니다.

- **폰** — 주소를 연 뒤 「홈 화면에 추가」 하면 앱처럼 열립니다
- **PC** — 즐겨찾기에 두거나, 파일을 내려받아 인터넷 없이도 씁니다

## 담는 방법

| 방법 | 설명 |
|---|---|
| 붙여넣기 | 한글 공문에서 `Ctrl+A → Ctrl+C` 후 붙여넣으면 바로 읽습니다 |
| 파일 | 한글(.hwp·.hwpx) · PDF · 엑셀(.xlsx) · CSV · 텍스트 |
| 글자 스캔 | 폰에서 입력칸을 길게 눌러 「텍스트 스캔」 — 카메라로 공문을 비추면 입력됩니다 |

## 일정은 어디에 저장되나요

**쓰는 사람의 기기 안에만** 저장됩니다. 어떤 서버로도 전송되지 않고, 만든 사람도 볼 수 없습니다.

다른 기기로 옮기려면 두 가지가 있습니다.

- 일정마다 **「캘린더에 넣기」** — 본인 구글 캘린더에 들어가 폰·PC가 맞춰집니다
- **「백업 저장」** 으로 파일을 뽑아 다른 기기에서 **「백업 불러오기」**

기기를 바꾸거나 브라우저를 초기화하기 전에는 백업을 받아두세요.
